# Presen'it! 1.0 scope

This document freezes the **1.0.0** surface. Bug fixes may land before or after the tag; **new features do not** until a later minor/major, unless the maintainer explicitly reopens scope.

## In scope for 1.0 (already shipped through 0.9.x)

- CLI: `presenit init | dev | build | export`
- Authoring: single `src/<slug>/slide.md`, HTML-comment directives, frontmatter listed in README / `llms.txt`
- Viewer: projection, overview, presenter (separate tab), blackout, laser, timer controls, page transitions, click zones
- Rich content: GFM-ish Markdown, task lists, GitHub alerts, Shiki, KaTeX, Mermaid
- Themes: `light` / `dark` + `hue`, fonts, footer, title/description (OGP)
- Packaging: npm `@axt_ayakoto/presenit`, GitHub Pages one-pager

## Explicitly out of scope for 1.0

Do **not** treat these as missing 1.0 requirements:

- Slide fragments / incremental builds
- Extra layout engines (title/section/grid templates beyond columns + center)
- Background images / logos as first-class authoring
- Custom CSS / theme packs beyond current frontmatter
- Video / iframe / audio embeds
- Image fit DSL
- PDF speaker-notes / handout variants
- Overflow UI beyond console/export warnings
- Multi-deck picker UI
- Extra a11y work beyond what already ships
- PPTX or other non-PDF export
- Phone remote control
- Laser drawing / pen tools
- Discord-style markup (`-#`, `__underline__`) — closed as wontfix earlier

## Compatibility (SemVer)

Starting with **1.0.0**, treat the following as the public contract:

| Surface                                                         | Stability |
| --------------------------------------------------------------- | --------- |
| CLI commands & flags (`init`, `dev`, `build`, `export`)         | Stable    |
| Frontmatter keys documented in README / `llms.txt`              | Stable    |
| Directives (`slide-break`, `column-break` + documented options) | Stable    |
| Markdown dialect described in README / `llms.txt`               | Stable    |
| Package entry `exports` / published `files` needed by consumers | Stable    |

Rules of thumb:

- **Patch** (`1.0.x`): bug fixes, docs, internal refactors that do not change the contract above
- **Minor** (`1.x.0`): backward-compatible additions (new optional frontmatter, new CLI flag with default off, additive Markdown)
- **Major** (`2.0.0`): breaking changes to the contract (rename/remove frontmatter, change directive syntax, remove CLI commands, break published paths)

Undocumented APIs, private modules, and visual pixel-perfection of themes are **not** covered by the compatibility promise.

## Process note

Until 1.0.0, maintainers auto-merged and auto-released. **After 1.0.0**, releases require an explicit request (see `.cursor/rules/pre-1.0-release.mdc`).
