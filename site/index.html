Presen'it!

Markdown のまま、
登壇に耐えるスライドへ。

読み物として自然な単一ファイルを、少ない宣言だけで組版。投影・Presenter・PDF まで一つのツールで。

使い始める GitHub リポジトリ

Install

Node.js ≥ 22 · プロジェクトに入れて使うだけ

pnpm add -D @axt_ayakoto/presenit
pnpm exec presenit init my-talk
pnpm exec presenit dev my-talk

詳細な frontmatter・ディレクティブ・ショートカットは README が正本です。

投影の操作（要約）

  • ← → 前後 · P Presenter · O Overview
  • B ブラックアウト · L レーザー · F フルスクリーン
  • 左下ホバーでツールバー（Presenter / Laser など）
